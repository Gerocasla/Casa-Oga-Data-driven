# Recordatorios — Casa Óga Data Driven (Grupo 1)

Carpeta de notas de trabajo para no perder contexto entre entregables. **Leer antes de empezar cualquier entregable o consolidado nuevo.**

| Archivo | Para qué sirve |
|---|---|
| [00-contexto-proyecto.md](00-contexto-proyecto.md) | Qué es el proyecto, dónde está cada cosa (carpetas, repo), cifras insignia |
| [01-reglas-de-entrega.md](01-reglas-de-entrega.md) | Reglas fijas: consolidado final, sección de Cambios, qué va en cada tipo de entrega |
| [02-correcciones-tp1.md](02-correcciones-tp1.md) | Feedback de la cátedra sobre el Entregable 1 — checklist de correcciones pendientes |
| [03-registro-de-cambios.md](03-registro-de-cambios.md) | Log acumulado de cambios hechos a entregables ya presentados (fuente de la sección "Cambios" del consolidado) |
| [04-tp2-eda-pendientes.md](04-tp2-eda-pendientes.md) | Entregable 2: estado, qué pide, preguntas abiertas y discrepancias del EDA a decidir |
| [05-decisiones-modelo.md](05-decisiones-modelo.md) | Variable objetivo, semáforo y acciones: qué decidimos, en qué nos apoyamos y qué falta aprobar |
| [06-bitacora-trabajo-con-claude.md](06-bitacora-trabajo-con-claude.md) | Bitácora del trabajo con Claude (ago-sep 2026): criterios vigentes, cronología, números de referencia y pendientes. **Punto de partida para retomar.** |

## Cómo mantener esta carpeta
- Cada vez que llegue feedback nuevo de un TP → crear `0X-correcciones-tpN.md` con el mismo formato que el del TP1.
- Cada vez que se aplique una corrección → marcarla `[x]` en su archivo de correcciones **y** anotarla en `03-registro-de-cambios.md`.
- Solo archivos `.md`.
